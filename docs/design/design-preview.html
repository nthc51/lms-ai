Tìm kiếm nhị phân

Tìm kiếm nhị phân áp dụng cho mảng đã sắp xếp. Ở mỗi bước, thuật toán so sánh phần tử ở giữa khoảng tìm với giá trị cần tìm, rồi loại bỏ một nửa khoảng không thể chứa đáp án. Nhờ vậy số bước giảm theo cấp số nhân.

Với mảng có n phần tử, số lần so sánh trong trường hợp xấu nhất là khoảng log₂ n. Một mảng một triệu phần tử chỉ cần khoảng 20 lần so sánh.

def binary_search(a, x):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == x: return mid
        if a[mid] < x: lo = mid + 1
        else: hi = mid - 1
    return -1

Lưu ý điều kiện dừng lo <= hi: nếu viết lo < hi sẽ bỏ sót trường hợp khoảng tìm chỉ còn một phần tử.

Vì sao điều kiện dừng là lo <= hi mà không phải lo < hi?

Khi khoảng tìm chỉ còn một phần tử thì lo == hi, và phần tử đó vẫn cần được so sánh[1]. Nếu dùng lo < hi, vòng lặp dừng sớm và bỏ sót phần tử cuối cùng[2].
